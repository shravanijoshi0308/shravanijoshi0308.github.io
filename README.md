## How it's built

- One `index.html` file with HTML, CSS and plain JavaScript. No frameworks and no build step.
- Animated background: a map of my tech stack drawn in SVG, with flowing connections and a moving network of points on a canvas
- Typing animation, count-up numbers, fade-in on scroll and cards that follow the mouse
- Works on phones and desktops, and switches to a calm version for visitors who turn off animations on their device
- Hosted for free on GitHub Pages

## Run it locally

Download `index.html` and open it in any browser. That's it.
